Step-by-step deployment guide for Harsh Agrawal's portfolio using Bitbucket Pages and EmailJS

Prerequisites & local setup
1
Install Node.js free
Download and install Node.js v18 or higher. This gives you npm to run the project.
nodejs.org → click "LTS"
After installing, open Terminal and verify: node -v should print v18 or higher.
2
Download and extract the portfolio zip
Download the portfolio_harsh_agrawal.zip file from this chat. Extract it to a folder on your computer — for example your Desktop.
cd ~/Desktop/portfolio
3
Install project dependencies
Run this once inside the portfolio folder. It downloads React, Vite, and EmailJS packages.
npm install
4
Test it locally
This starts a live preview at localhost:5173 in your browser. Every change you save updates instantly.
npm run dev
Open http://localhost:5173 in your browser. You should see your portfolio running locally.
5
Add your resume PDF
Copy your resume PDF into the public/ folder and name it exactly resume.pdf. The download button in the navbar will serve it automatically.
portfolio/ public/ resume.pdf ← drop your file here
Wire contact form → your Gmail inbox (free, no backend)
1
Create a free EmailJS account
Go to emailjs.com and sign up. Free tier gives you 200 emails/month — more than enough.
emailjs.com → Sign up free
2
Connect your Gmail
In the EmailJS dashboard: click Email Services → Add New Service → choose Gmail → click Connect Account → sign in with your Gmail. Note the Service ID it gives you (e.g. service_abc123).
EmailJS connects via OAuth — it never stores your password.
3
Create an email template
Click Email Templates → Create New Template. Paste this exact template body:
Subject: Portfolio contact: {{subject}} From: {{from_name}} <{{from_email}}> {{message}}
Set To Email to your Gmail address. Save and note the Template ID (e.g. template_xyz456).
4
Get your Public Key
In the EmailJS dashboard go to Account → General. Copy your Public Key (e.g. abcDEF123_xyz).
5
Paste the 3 keys into Contact.jsx
Open src/components/Contact.jsx in any text editor (VS Code, Notepad, etc). Find these 3 lines near the top and replace the placeholder values:
const EMAILJS_SERVICE_ID = 'service_abc123' const EMAILJS_TEMPLATE_ID = 'template_xyz456' const EMAILJS_PUBLIC_KEY = 'abcDEF123_xyz'
Run npm run dev and test the contact form. You should receive an email in Gmail within seconds.
Create Bitbucket repository & initialize Git
1
Create a Bitbucket account (if you don't have one)
bitbucket.org → Sign up free
Note your Bitbucket username — you'll use it in the next step.
2
Create a new repository with this exact name
In Bitbucket: click + → Repository. Set the name to exactly your username followed by .bitbucket.io. This naming convention is what activates free static hosting.
<your-username>.bitbucket.io Example: harshagrawal.bitbucket.io
The repo name must match your Bitbucket username exactly. harshagrawal.bitbucket.io not harsh-agrawal.bitbucket.io.
3
Install Git (if not already installed)
git-scm.com/downloads
Verify by running in Terminal:
git --version
4
Initialize Git inside your portfolio folder
cd ~/Desktop/portfolio git init git remote add origin https://<your-username>@bitbucket.org/<your-username>/<your-username>.bitbucket.io.git
Replace <your-username> with your actual Bitbucket username in both places.
5
Configure Git identity (first time only)
git config --global user.name "Harsh Agrawal" git config --global user.email "h3108.agrawal@gmail.com"
Build the production bundle & push to Bitbucket
1
Build the production files
This creates an optimized dist/ folder with your entire site as static HTML/CSS/JS files.
npm run build
You should see ✓ built in ~2s. A dist/ folder will appear inside your portfolio folder.
2
Create a .gitignore file
This tells Git to ignore the node_modules folder (it's huge and not needed in the repo).
echo "node_modules/" > .gitignore
3
Copy dist files to root and commit
Bitbucket Pages serves from the root of your repo's main branch. Copy the built files up and commit everything.
cp -r dist/* . git add . git commit -m "Initial portfolio deploy"
On Windows use xcopy dist\* . /E /H instead of cp -r dist/* .
4
Push to Bitbucket
git push -u origin main
Git will ask for your Bitbucket username and password (or app password). Enter them and the push will complete in a few seconds.
If you have 2FA on Bitbucket, create an App Password: Account Settings → App Passwords → Create. Use that instead of your regular password.
5
For future updates — one command
Whenever you update the portfolio content, run these 4 commands to rebuild and redeploy:
npm run build cp -r dist/* . git add . && git commit -m "Update portfolio" git push
Verify your live site
Your site is live!
After pushing, wait 1–2 minutes for Bitbucket to deploy. Then open your browser and go to:
https://<your-username>.bitbucket.io
First load might take up to 5 minutes. If you see a 404, wait a bit longer and hard-refresh with Ctrl+Shift+R.
Test the contact form
Open your live site, scroll to the Contact section, fill in the form, and hit Send. Check your Gmail inbox — you should receive the message within 30 seconds.
Test dark/light mode
Click the moon/sun icon in the top-right of the navbar to toggle between modes. Your preference is saved automatically.
Share your URL
Add it to your LinkedIn profile, email signature, and resume header. Your portfolio is now live and accessible worldwide — for free.
